## Buling — SOURCE_BLOCKED

Blocking fact: **Five Thunders Spell Array Continuous DMG**.

The pinned source provides an exact Lv1-Lv10 coefficient row (`value id 1307031`) under Buling's current Liberation/Forte source slice. The same move text states that the array deals Electro DMG every 2 seconds for 24 seconds. It does **not** state which Character damage-bonus bucket applies to the array's own damage.

This omission is material because the same source text explicitly says that the separate `Thunder Spell - Yin and Yang` and `Thunder Spell - Heaven, Earth, Mind` team states grant **Resonance Skill DMG Bonus**. Bellibing therefore cannot infer that the array's damage is Resonance Skill DMG merely because the surrounding state grants that bonus or because the array is generated by a Liberation-owned move.

Disposition: keep Buling without a canonical Character Mechanics profile until an authoritative current source explicitly classifies Five Thunders Spell Array Continuous DMG.

## Danjin — SOURCE_BLOCKED

Blocking fact: **Ruby Blossom full-power threshold**.

The pinned current source encodes the relevant description parameters as:

`[60, 120, 120, 120]`

The same source text simultaneously states:

- Danjin can hold up to **120 Ruby Blossom**;
- the enhanced Chaoscleave/Scatterbloom branch applies if current Ruby Blossom reaches **over 120**;
- the enhanced branch consumes **120 Ruby Blossom**.

`over 120` cannot occur if the same source's maximum is 120. Bellibing must not silently reinterpret `over 120` as `at least 120`, `equal to 120`, or another threshold even if one interpretation appears likely from gameplay.

Disposition: keep Danjin without a canonical Character Mechanics profile until the current source contradiction is resolved explicitly.

## Xiangli Yao — SOURCE_BLOCKED

Blocking fact: **Pivot - Impale damage-bonus classification**.

The pinned source provides exact Lv1-Lv10 rows for Pivot - Impale stages 1-3 (`value ids 1305015-1305017`). In the `Intuition` move text, Basic Attack and Heavy Attack are replaced by **Basic Attack Pivot - Impale**, which deals Electro DMG.

The same source paragraph explicitly says that Dodge Counter **Unfathomed** is considered Resonance Liberation DMG. Other enhanced Xiangli Yao actions are likewise explicitly classified when the source intends Resonance Liberation DMG. Pivot - Impale receives no corresponding statement.

Bellibing therefore cannot infer Resonance Liberation DMG from the fact that Pivot - Impale is available during the Resonance Liberation `Intuition` state. Nor can it assume Basic Attack DMG solely from the replacement action label when the project's verified source contract requires an explicit damage-bonus classification for damaging Character actions.

Disposition: keep Xiangli Yao without a canonical Character Mechanics profile until an authoritative current source explicitly classifies Pivot - Impale damage.
