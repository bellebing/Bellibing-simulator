# Echo Engine Boundaries

Echo Core owns verified Wuthering Waves mechanics and remains character-free.
Raw/source data flows through domain mechanics, profiles and presentation. Game truth must not move into UI to work around the build boundary.

The public browser build uses explicit entrypoints and an approved asset inventory. It retains the Echo mechanics needed for character-free generation, rolling, verified resource accounting and stat editing.

Improvement Cost / evaluator uses a private decision-engine contract. Proprietary policy and calibration are not part of the public repository.

Alpha evaluation, Roll Assist advice and Echo Lab evaluation/strategy outputs remain Pending. Build/Improve may show source-backed data and user-owned choices without evaluating them.
