# Bellibing public product contract

Bellibing provides Wuthering Waves Character Build / Improve presentation and character-free Echo mechanics.
CharacterBuildState owns actual equipment. Current and Candidate inputs remain separate, and saved user choices do not establish evaluation results.

Source-backed Character Target presentation preserves its source family, context and provenance. Missing or disputed game facts remain Pending/Unknown; missing is not zero.

Improvement Cost / evaluator uses a private decision-engine contract. Proprietary policy and calibration are not part of the public repository.

Build Need, Improvement Cost, broad Character comparison and evaluator qualification require their own source-/scenario-specific readiness evidence. Some local experimental advice/DPS capabilities exist only on **unmerged public/private Draft branches**; they are not qualified or deployed production features. Actual current availability is determined from GitHub/main and the appropriate private/runtime contracts, never from an older blanket Pending statement. The frontend must fail closed for unsupported calculations and must not implement substitute private decision logic.
