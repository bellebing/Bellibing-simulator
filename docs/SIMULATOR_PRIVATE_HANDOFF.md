# Simulator private-engine handoff

The public workstream owns explicit user Echo requirement checks, verified checkpoint mechanics, sandbox resources, actual stat projection and presentation. It supplies no economic Continue/Reject/Accept engine. An Echo passing requirements is not evidence of Character improvement; reaching a Character reference is not a completion rule.

## Dependencies for Bellibing Privat

- Support evolving simulated builds with 0–4 equipped Echoes; existing trusted pilots require five complete cards. Keep unsupported evaluation Pending.
- Define economic Continue/Reject/Accept against the evolving build and separate Tuners, Tube denominations and candidate Echo costs. No arbitrary public stat rejection or combined resource weights.
- Extend ER and supported Character/stat dimensions beyond existing bounded STAT_TARGET pilots; distinguish source references, custom minima and preferred targets.
- Define build completion separately from per-Echo requirement satisfaction and static Character target comparison.
- Provide a trusted adapter/connection with session, Character, build, candidate, settings and resource revisions; reject stale results after edits or navigation.
- Supply safe public explanations without proprietary rules, weights or calibration. Public mathematical impossibility rejection is a separate deterministic requirement check.
- Specify supported discard/recovery economics before integrating refunds. Canonical effective EXP refunds do not prove material-denomination conversion.
- Define statistical Expected and repeated-run cost distributions with sample basis and unsupported paths. Actual simulated stats must never be relabeled Expected.

## Public budget and checkpoint contract

Apply new total budget deducts the session’s committed spending, including verified +25 cap returns, while preserving cards/history. It does not treat the edited amount as additional resources. A partial candidate stopped for resource exhaustion stays inspectable; starting a fresh run archives it as unplaced. Discard recovery remains unsupported. Unlimited toggle remembers prior finite counts only during the page lifetime.

## Public delivery tracking

The approved workstream consists of target/status clarity, shared cards/history, resource editing and checkpoint requirement control, followed by browser/build/CI verification. Implementation and exact-head evidence belong to GitHub. Private dependencies can be planned before visual polishing finishes.

Later product ideas: physical pile hover browsing, returning a discarded Echo, per-slot cost graphs and remaining improvement potential. These are not prerequisites for the current public delivery.
