# Bellibing layout & motion — retired visual rulebook

**Owner decision 2026-11-05:** All prior prescriptive layout hierarchy, exact spacing/breakpoints, max widths, carousel geometry, card positioning, animation durations/easings and responsive design rules in this file are retired. Find them in Git history only when useful as inspiration.

No replacement design rulebook is imposed. Use the current user's brief and actual real-browser visual review.

Technical correctness still matters: controls must work, content must be usable, account data must be safe, existing behavior must not break inadvertently and relevant browser/build tests must pass. These are engineering checks, **not** mandatory historical visual compositions.

The retained font identity is in [UI Typography](UI_TYPOGRAPHY.md). Relevant functional/data rules remain in the code and domain contracts.
