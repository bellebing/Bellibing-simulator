# Bellibing typography — retained font identity

**2026-11-05 reset:** Only font identity is retained as a visual convention. Former font sizing, label placement/wrapping, card geometry, line-height and layout rules are retired.

- Display/brand font: **ETNA** (accepted v34 family).
- Utility/body font: **Inter** with system sans fallback.
- Existing family declaration: `font-family: "Etna", Inter, sans-serif;`

Historical v34 external font reference: `https://db.onlinewebfonts.com/c/3c1a4128f95e2109303b045eda4bfe8a?family=Etna` (reference only, not evidence of redistribution permission).

Candidate official source: WILDTYPE ETNA Free Font by Krišjānis Mežulis, `https://wildtype.design/product/etna-free-typeface/`. The WILDTYPE license and creator Gumroad product have conflicting personal/commercial-use wording; clarify relevant use rights before self-hosting or shipping font binaries. Do not substitute an unverified lookalike.

Everything else in typography and layout is chosen for the present design request and verified visually.
