# Ciaccona owned-build product combat context — 2026-08-31

This note records the independently reviewed product benchmark used by `ciaccona-cartethyia-aero`. It is not a generic Wuthering Waves combat default.

- Tactical Hologram: Lorelei VI.
- Difficulty VI target level: 100.
- Level-100 DEF: 1592.
- Aero RES: 10%.
- Benchmark state is before 180 seconds and contains no successful Dodge during Ciaccona's fixed 4.5-second direct rotation.
- Therefore Lorelei's Dodge-triggered Ripple and 180-second Death's Dance modifiers are not applied. Sea Wind changes Max HP only and does not modify these direct DPS inputs.

## Locked team handoff

Canonical team: Cartethyia / Ciaccona / Rover (Aero).

The reviewed Rover (Aero) support preset uses Bloodpact's Pledge R1. The source-established sequence casts Unbound Flow P1 before switching out; the exact trio rotation enters Ciaccona immediately afterward. Bloodpact R1 grants nearby on-field Resonators 10% Aero DMG Amplification for 30 seconds after Unbound Flow, so that window covers Ciaccona's fixed 4.5-second direct rotation.

Only that 10% Aero amplification is promoted into the external Ciaccona product context. Cartethyia Outro is not applied because this supported handoff enters Ciaccona from Rover (Aero), not Cartethyia. No teammate ATK, CRIT or ER bonus is inferred.
