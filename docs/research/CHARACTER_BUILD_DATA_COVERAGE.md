## Recommendation policy: three separate layers

1. **Verified game facts**: Character identity/Level-90 stats, raw Echo/Weapon/Sonata, exact effect text, mechanics and source conflicts. Canonical provenance matters. A value present in a file is not automatically VERIFIED; modeled source text is not automatically executable.
2. **Source-based recommendations with context**: Character role/mode, team, equipment, weapon rank and source-rotation assumptions determine the meaning of a weapon, Sonata set, main Echo, Echo COST/main stats and stat priorities. Signature or Best in Slot is **only a source-relative relation**, not a universal optimum. An unlisted alternative is not disproved.
3. **Future Bellibing evaluation**: compare eligible alternatives against the user's *actual* Current/Candidate Echoes, weapon, team, owned equipment, constraints and executable effects. Source Calc totals, relative guide rankings and SOURCE_SEQUENCE_ONLY rotation descriptions must never be reported as a working evaluator/DPS model.

Data ownership stays separate: raw data → Character/Weapon/Echo/Sonata effects → conditional recommendations/profiles → combat/DPS → UI. Legacy V9.15 is not the current architecture.
