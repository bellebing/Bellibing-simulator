## Minimum decisive client observations (3 targeted captures)

All captures must disclose client version/build, date/platform, the same Echo identity, **Sync Tuning OFF**, `expBefore`, all four Tube counts, Shell balance, selected materials, **UI preview**, confirmation, **post-commit Shell balance**, new EXP/progress display and item balances. Record tuner debits separately; no assumed hidden auto-tune. Do not treat the preview as a debit.

1. **One Gold, then +10:** Fresh rank-5 +0, select exactly **one Premium (5,000)**. Screenshot `+5` **preview cost** (candidate 500), confirm and prove **actual 500** if true, `+5 600/1,700`, and one Gold consumed. Without resetting the Echo, add **six Advanced Tubes (12,000)**: candidate `expBefore 5,000 → expAfter 17,000`, **1,200 additional upgrade Credits**, `+10 500/3,600`; compare **actual** second debit. A bill based on 12,600 or a return/reset of the initial 600 would disprove the candidate. Tune +5 and +10 explicitly, in independently auditable transactions.
2. **Cap return receipt:** On a separate fresh +0 rank-5 Echo, record four Tube holdings. Select exactly **72 Advanced = 144,000 EXP** with no other material. Confirm the already-known **14,260 preview** against the **actual 14,260 Shell debit**, then record **post-commit count changes for Gold, Advanced, Medium, Basic**. Test specifically whether the 1,400 excess becomes **one Medium + 400 unrepresented**, a different denomination receipt, or a UI adjustment to selected Tubes. If the UI blocks the selection, record the block instead of inventing the result. This is not Data Recovery.
3. **Non-Tube rounding and donor-vs-recipient debit:** Prepare a disposable donor with **exactly 4,500 EXP** from nine Basic Tubes (not merely +5 level eligibility); document whether direct feed presents **3,375 effective EXP**. Feed it to a separate fresh Echo with no Tube material. Capture the quote and *actual* Shell delta for the fractional candidate **337.5**, then repeat with an identically prepared donor into the **same recipient** to distinguish per-transaction versus cumulative rounding. Record if source rounding/normalization prevents 3,375. As a separate integral-price cross-check, feed a +25 donor (expected **106,950 feed EXP / 10,695 new-recipient Credits** per W3-1); measure, do not infer. Never conflate donor's old expenditure with recipient's fresh fee.

**Stop condition:** If any controlled action cannot be performed, retain its corresponding `PENDING` cell. Keep source statements, previews, game balance changes and math as separate evidence classes. Neither these source additions nor the existing exact-Tube model establish B2's entire transaction contract.
