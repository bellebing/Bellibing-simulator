# Interactive Echo advice in Improve

SIMULATE reveals one canonical checkpoint at a time. CONTINUE observes the next
checkpoint; DISCARD requests actual recovery and stages a fresh eligible Echo.
The existing source-model investment checkbox enables Current-bound private advice
using the actual selected Character/team/equipment. A useful observed +25 is kept
as a modeled improvement even below ideal Echo requirements. SEARCH BETTER preserves
that incumbent as the subsequent comparison baseline. Equal/lower DPS keeps Current.

Current-bound choices compare sampled completion upgrade chance and net Tuners,
including actual recovery, over bounded canonical completion lookahead. The model
recomputes after observations; it does not claim exact eventual completion cost,
global finite-budget optimality or gameplay-qualified DPS. Unsupported source
contexts remain Pending. Without Current analysis, the existing exact Echo-target
advice retains its gross-Tuner/one-attempt semantics and configured Gate.

## Resources and ownership

Canonical whole-Tube spending preserves carry, checkpoint eligibility and +25
returns. All slots share one detached simulated budget while retaining their own
observed prefixes and RNG state. Recovery uses the existing 75% invested EXP and
30% Tuner fractions. Data Recovery returns Premium first, then Advanced, Medium
and Basic, discarding the final remainder from actual invested XP including carry.
See [the owner source disposition](../../data/source/echo-recovery-owner-confirmation.json).
Fractional direct-feed XP uses owner-approved nearest-integer half-up rounding as
an explicit model assumption rather than a verified game rule.

Recovery proposals are asynchronous and bound to donor/destination identity and
revision. Both recovery and next-reveal affordability validate before the live
owner commits destruction or advances RNG. Stale/repeated replies cannot duplicate
returns. Histories distinguish recovered donors, fed donors and retained cards.
The resource table shows simulated net expenditure; denomination conversion can
produce a negative net count for a particular Tube type. Saved stock is unchanged.

Gate/minimum/resource edits reanalyze the same observed rolls. Slot switches retain
prefixes; owner/build/Character/model changes retire the workspace. Abort freezes
it, Reset clears it, and Export saves detached local observations/history. No
operation equips an Echo, debits account stock or overwrites saved Current.

## Transport and verification

The existing local launcher connects the same-origin bridge to the private bounded
stdio entry. Existing server transport discovery can use the authenticated private
team action for advice/recovery. Missing service/configuration leaves Pending.
Private policy, DPS algorithms, models and diagnostics remain outside browser
bundles. This implementation does not activate or deploy a hosted service.

Focused final local checks cover canonical session spending, shared-slot budgets,
stale recovery replies, Current capture and local review transport. The private
desktop Chromium check exercises real controls, all checkpoints, recovery/net
presentation, Current requests, Export/Abort/Reset and byte-identical account
storage. Evidence stays private. Mandatory repository GitHub checks still precede
merge; no historical roster or benchmark campaign is repeated.
