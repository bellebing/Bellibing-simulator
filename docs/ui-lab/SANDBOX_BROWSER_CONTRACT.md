# Local Sandbox browser contract

The Sandbox preview connects asynchronously to a separately started **local, same-origin** host. Static previews retain Pending results when that host is absent. The Sandbox UI shows a persistent `Preview only` status and disables SIMULATE until a valid response from the local host's existing metrics contract. While unavailable it retries at a bounded interval, enabling SIMULATE if the host becomes reachable; server capability and run validation remain authoritative. A valid host `/metrics` response with `status: PENDING` keeps SIMULATE disabled for that selected context, and presents an accessible explanation derived only from safe server `reasons`. The generic `CONFIGURATION_CAPABILITY_PENDING` covers Character, Weapon or Settings without attributing which is unsupported. Run-level `PENDING` is likewise translated, with the original reason code available in the status tooltip; none of these are promises of execution. This contract does not authorize a production endpoint or deployment.

`BELLIBING_SANDBOX_HTTP_V1` supplies `POST /sandbox/v1/guest`, then CSRF-protected `POST /metrics`, `POST /runs`, and `POST /runs/:id/{step,abort,reset}`. Mutating calls carry a scoped `Idempotency-Key`; an uncertain network retry retains the same key. Each new `start()` without an explicit seed generates a fresh random UUID seed; an explicitly provided seed stays reproducible. A network retry of that `POST /runs` reuses the same serialized body (including seed) and the same idempotency key. `GET /runs/:id/export` also carries the CSRF token. Cookies are same-origin credentials; server ownership, authentication, limits and atomic commit validation remain host responsibilities.

Metrics and run creation capture the actual detached workspace context, including Character/build, Weapon, selected active slots, Settings and resource inventory revisions. Browser revisions are freshness tokens, never authorization. Step/abort sends only the server run identity and expected server revision. Each accepted operation advances that revision once; internal engine checkpoints may advance more often.

The client compares the complete captured owner snapshot and an opaque generation before accepting any response. Character/Weapon/Settings/resources/template/selection/mode/reset changes invalidate presentation and late results. Reset clears the presentation immediately and retires the server run. Server-side session invalidation is independent of the browser's checks.

Actual observed Current, Candidate and Trash are rendered through a read-only overlay. Incomplete retained Current is labelled Temporary. These cards never overwrite input templates, account Current, inventory or public Session owners. Trash inspection preserves actual observed pairs and the supplied disposition reason. Export downloads the host's allowlisted presentation JSON only while the originating run ID and server revision remain current, and only with its versioned export envelope. Private replay inputs, coefficients and policy details are not browser inputs.

Expected Echoes/Tuners display only independently certified matching metric cells. Expected Tubes remains Pending. Simulated cost comes from actual gross receipts, retaining denominations for Gold-equivalent display. The host binds comparison to Character, goals, selected slots/templates, sources and policy. Only completed Unlimited runs show actual-minus-expected differences; Expected is a statistical mean, never a promised outcome. Finite-budget and incomplete runs retain actual spend with a Pending matching comparison. The explicit `Unlimited for cost comparison` action sets all existing resource counts and invalidates old results.

All 59 released Characters can submit explicit Custom Echo-only goals where the existing canonical policy supports them. Fifteen without canonical Recommended contexts receive only a source-bound Sandbox identity; targets and recommendations are not invented. Existing source-review failures and unsupported minima/gates stay Pending. Source template coverage is distinct from executable-goal coverage.

DPR remains an experimental observed substat proxy. Normal selected Augusta, Iuno or Shorekeeper can show a separate `Experimental Simulated · fixed reference trio` panel through the existing reference scenario. Five actual finished selected-member Echoes, two fixed reference builds, source/equipment/baseline and whole-build ER gates remain required. It does not qualify the source team above. Observed alternatives use the same scenario for before/after deltas. Statistical Expected DPS and qualified normal DPS remain Pending. Evaluation-context changes invalidate runs and metrics separately from canonical build ownership.

The observed Echo Workshop uses expandable canonical +5/+10/+15/+20/+25 pairs, advances after a valid value and preserves complete stat/value pairs during an explicitly confirmed swap. Cancel and Undo preserve detached draft semantics; incomplete selected values block commit. Incomplete pair moves remain Pending. Simulation templates continue to contain no observed substats and cannot manufacture rolled Echoes.
