# Simulation Stats

The existing right panel has Character Stats and Simulation Stats modes. Character Stats uses the approved Elegant Hero by default, saved-equipment presentation, expandable Skills and saved value column. `?hero=baseline` and `?hero=cinematic` remain reviewable; the earlier implementation is recoverable in git.

Simulation Stats is a separate result view in the same outer panel. A 92px Character artwork banner replaces the oversized heading. Twelve canonical Character stats each occupy one horizontal row with aligned Stat, Recommended, Expected and Simulated columns. Typography matches Echo substats on wide panels; narrow panels tighten column proportions and type while retaining single-line labels and values. There is no inner scroll region. Wide panels grow to 24% of the composition, capped at 480px. The Workshop retains its 1000px minimum. The measured layout gap participates in the fit calculation. At 1440px the established last-interacted side-panel priority applies: opening one expanded side panel compacts the other. Both modes share identical outer dimensions.

## Data ownership

- `tools/export-targets.mjs` calls `projectCharacterTargetPresentations()` from the canonical source-verified modern DEFAULT Calc contract. `modules/targets.js` is generated; `--check` detects drift. General recommendations, Prydwen and legacy scenarios never fill missing rows. Exact source references survive beside formatted values.
- `modules/simulation-model.js` binds canonical result identities to the existing saved-stat row order. Recommended, Expected and Simulated never substitute. Missing values are null, displayed as an em dash with an accessible unavailable label/tooltips. Observed zero is retained.
- Augusta/default Expected is now a **source-weighted conditional average of five accepted +25 Rank-5 Echoes**, using current Hard + explicit Flex acceptance settings. The exact, character-free conditional substat distribution is in `src/expectedEchoStats.mjs`, with probabilities generated into `settings-catalog.js` from `src/echoCoreRules.ts`. It conditions on every Hard requirement and at least N passing distinct Flex members, then includes all remaining filler substat expectations. It is deterministic and does not run RNG or spend resources. A +5 Gate can save resources by discarding impossible cards; conditional finished-Echo stat quality is independent of that early rejection checkpoint. Other Characters without an approved Expected context remain unavailable.
- Augusta's five approved 4/3/3/1/1 CRIT/Electro/Electro/ATK/ATK templates are combined with the current canonical Augusta level-90/intrinsic data, Thunderflare Dominion R1 verified static data, exact Rank-5 +25 Main Stats and the existing canonical `projectStaticBuildStats` producer. The resulting twelve numbers are **static projection only**, not complete in-combat totals: the producer explicitly omits Sonata and other conditional effects. The separate `recommended` and `simulated` columns retain their existing source semantics.
- Enabled valid ER Target conditions the **joint five-Echo result** on final total ER reaching the threshold; disabled ER Target does not constrain Expected. If the required combination is impossible, Expected is unavailable, not zero. The target is not automatically an individual Echo requirement. No budget, evaluator, accept-best policy or RNG outcome is implied.
- Simulated uses the existing second-column illustrative record only after `hasRecordedRun`; it is visibly identified as an illustrative run. It is never the Character Stats saved column.
- Demonstration → **Illustrative focus demo** enables `result-fixtures.js`: eight explicitly illustrative CRIT Rate keyframes and one affected Expected result ID. They are not computed from minimum roll amounts and have no domain authority. Other Characters and actions have no supplied numerical relationship.

## Contextual focus contract

`present(nextModel, affected)` accepts an external presentation and explicit `{id, role}` result identifiers. Value changes without an affected relationship update plainly. A relationship without a real changed, available value never animates. Unknown/new unsupported relationships remain inactive. This interface supports future resource/feasibility, Sonata, Gate, Hard/Flex and Character Target producers without declaring that each action changes a Character statistic.

The explicit illustrative fixture adapter responds to CRIT Rate slider input only when the demonstration toggle is enabled, using an explicit control-to-canonical-metric binding; no displayed-text matching. Only its Expected cell and owning row gain focus. Normal Augusta settings edits now provide actual changed calculated Expected fields, independent of the demonstration. Unrelated result rows recede slightly; Echoes, saved stats and the Workshop never dim or highlight. A short eased counter retargets from its current displayed value during dragging, followed by one small vertical settling motion and a fade. Reduced motion updates instantly with static emphasis. Keyboard input follows the same path; live announcements are debounced.

Editing reveals Simulation Stats once per session without expanding a compact panel or moving keyboard focus. A manual mode choice takes precedence for the remainder of the session. The explicit demo toggle intentionally reveals and opens results for review. Neither mode switching nor focus writes equipment, settings, simulation or persistence state.
