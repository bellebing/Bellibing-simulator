# V1.1 readability refinement

The approved V1.1 is recoverable at `46691a0c04380c10d2108964f7bae3141d8700ea` (before this refinement). V1 and its asset hash manifest remain untouched.

The Lab-only scale in `v1.1/typography.css` uses 10px metadata, 12px ordinary information and controls, 14px section emphasis/secondary stats, 16px item titles/Main Stat labels, 20px panel headings, 22/26px primary values, and 28/34px page/Character identity. ETNA retains its existing heading role. Symbols are separate from the text scale.

Echo variants inherit one hierarchy using card role variables; compact cards reduce titles and primary values while retaining 12px substats. Spacing compensates for type changes to preserve the approved composition and artwork. Selection uses restrained gold fills/borders, hover feedback and visible keyboard focus; informational rows stay unboxed. SELECTED describes slot focus, ACTIVE describes equipment state.

Materials are explicit presentation records. Zero consumption is omitted, unavailable data is retained as unknown, and no quantities are calculated. Scope selection is per-Character memory state; it does not run a simulator. One accessible Demonstration disclosure explains these boundaries.
