# Approved Visual Concept V1 — preserved baseline

This is the exact approved standalone V1 implementation from the UI Lab design review, saved before the V1.1 integration. `baseline.json` pins every original source and artwork file by SHA-256. This baseline is intentionally immutable; V1.1 lives in the sibling directory.

Open `index.html` through a static server, or run `python3 -m http.server 4180 --bind 127.0.0.1` at the repository root and visit `/docs/ui-lab/v1/`.

All builds, resources and histories are demonstration fixtures. This page has no production simulator, account reader or persistent storage. Existing ETNA source and original fan-companion artwork contracts remain applicable. Artwork bytes are copies of the already reviewed prototype assets; `v1.1` reuses these files rather than copying them again.
